Neuvto WOS · Architecture Reference

A platform, not an app.

Neuvto WOS is a multi-tenant Workforce Operating System. Leave Management is the first of eleven planned modules — and it is built so that the second one is cheap. These nine plates show how, and what carries it into production.

Version 1.1 7 August 2026 Status Live in production

What this document is. It describes the architecture as built. The platform layer and the Leave module are both implemented, deployed, and serving neuvto.com from the pipeline in Plate 05. Every module name and target quarter comes from the product roadmap; nothing here is estimated or embellished, and where something is decided but not yet built it says so in those words.

Stack
